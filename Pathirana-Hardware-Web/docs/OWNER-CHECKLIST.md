# Owner checklist — information needed before / after launch

The website only shows information that has been confirmed. Please provide or confirm the items below. Each one
is entered in a single file (`src/content/business.ts`, `services.ts` or `gallery.ts`) — see the README.

## Needed to launch

- [ ] **Website domain** (e.g. `www.pathiranahardware.lk`) — required for search-engine canonical URLs and the sitemap.
- [ ] **Review all page text** (Home, About, Services, Gallery, Contact) and approve it.
- [ ] **Confirm the map location** — open the “Search on Google Maps” link. If the result is wrong or unclear,
      send the exact Google Maps place link (Share → Copy link) for the store.

## Recommended

- [ ] **Opening hours** (each day, including closed days and holidays if relevant).
- [ ] **Delivery details** — is delivery offered? Which areas? Any charges or minimum order? Typical timing?
- [ ] **Reservations** — how do they work (by phone? how long are items held? deposit?).
- [ ] **WhatsApp** — is `071 225 9699` (or another number) used for WhatsApp enquiries?
- [ ] **TikTok** — confirm the profile link for handle `pathiranahardwar`.
- [ ] **Product categories / brands** you want listed (only those regularly stocked).
- [ ] **Year established** (optional).
